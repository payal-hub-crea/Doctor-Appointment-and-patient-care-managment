# Hospital Appointment Management System

## Overview
This is a web-based Hospital Appointment Management System developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- Patient Registration
- Patient Login
- Appointment Booking
- Appointment Management
- Secure Authentication
- User-Friendly Interface

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Installation
1. Install XAMPP.
2. Copy the project folder to the `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Import `appointment.sql` into phpMyAdmin.
5. Open the project in your browser.

## Database
Database file: `appointment.sql`
